#  Flashcard App (Static Deck)

##  Project Overview
The Flashcard App is a simple and responsive web application built using HTML, CSS, and JavaScript. It helps users learn and revise concepts through interactive question-and-answer cards.

Users can flip a card to reveal its answer and navigate between cards using the Next and Previous buttons.

## ✨ Features
- 📖 10 flashcards with questions and answers.
- 🔄 3D flip animation on clicking a card.
- ⏭️ Next button to move to the next flashcard.
- ⏮️ Previous button to revisit the previous flashcard.
- 📊 Progress bar showing the current card progress.
- 🔢 Card counter displaying the current card number.
- 📱 Responsive design for mobile and desktop screens.
- ⚡ Static data with no API required.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Click a flashcard to reveal the answer.
5. Use the Next and Previous buttons to navigate between cards.
6. Follow the progress bar to track your position in the deck.
